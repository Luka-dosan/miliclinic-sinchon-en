# Mili Clinic Dosan — English Website

Static HTML website for Mili Clinic Dosan's international patient page.

## Structure

28 static HTML pages, each self-contained with inline CSS.

- `index.html` — Homepage
- `about.html`, `brand-story.html`, `tour.html`, `equipment.html`, `schedule.html`, `location.html` — Clinic info
- `ulthera.html`, `thermage.html`, `tuneface.html` — Lifting treatments
- `reborn-cell.html`, `fit-culptra.html` — Body treatments
- `minimal.html`, `silhouette-soft.html`, `sculptra.html`, `juvelook.html`, `juvederm.html` — Minimal surgery
- `skin-recovery.html`, `skin-booster.html`, `all-in-one-brightening.html`, `derma-renewal.html`, `anti-trouble.html` — Skin recovery
- `laser-hair-removal.html` — Hair removal
- `skin-care.html`, `medispa.html`, `highend-medispa.html`, `antioxidant-iv.html` — Skin care
- `promotion.html` — Seasonal programs

## Tech

- Pure HTML/CSS/JS — no build step
- Hosted on Vercel
- Deployment: auto-deploy on push to `main`

## Development

Edit HTML files directly. Push to `main` to deploy.

```
git add .
git commit -m "describe change"
git push
```
